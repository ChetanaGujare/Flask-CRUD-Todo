# 📋 Flask CRUD Todo — Full-Stack Task Manager

A modern, full‑stack task management application built with **Flask** (backend API), **MySQL** (database), and **HTML/CSS/JS** (frontend). It features a beautiful glass‑morphism UI with dark/light mode, real‑time progress tracking, and complete CRUD operations.

## ✨ Features

### Backend (Flask API)
- ✅ **GET** all todos  
- ✅ **GET** a single todo by ID  
- ✅ **POST** create a new todo  
- ✅ **PUT** update an existing todo (toggle completion)  
- ✅ **DELETE** remove a todo  
- ✅ MySQL connection pooling for performance  
- ✅ Environment variables for security  
- ✅ CORS enabled for frontend integration  
- ✅ Comprehensive error handling with proper HTTP status codes  

### Frontend (HTML/CSS/JS)
- ✅ Interactive todo list with real‑time updates  
- ✅ Visual progress ring and progress bar  
- ✅ Filter tasks by status (All / Pending / Done)  
- ✅ Dark/Light mode toggle (saved in localStorage)  
- ✅ Glass‑morphism design with floating gradient backgrounds  
- ✅ Fully responsive — works on mobile, tablet, and desktop
